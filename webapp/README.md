# 基金股票个人账户管理（网页版）

这是一个单容器、SQLite 持久化的个人投资记录工具。数据保存在 `data/portfolio.db`，适合放在 NAS 的 Docker 项目目录中。

## 本地运行

```bash
python3 server.py
```

打开 <http://127.0.0.1:8080>。

## NAS / Docker 运行（GitHub 公有仓库）

程序代码放在 GitHub 私有仓库，真实账户数据只保存在 NAS 的
`webapp/data/portfolio.db`，不会提交到 GitHub，也不会被重新构建容器覆盖。

### 首次部署

在 NAS 的 Docker 项目目录克隆仓库，然后启动容器：

```bash
git clone https://github.com/wangluoyigithub/portfolio-tracker.git portfolio-tracker
cd portfolio-tracker/webapp
cp .env.example .env
docker compose up -d --build
```

部署前编辑 `.env`，把 `PORTFOLIO_BIND_IP` 设置为 NAS 的局域网 IP，例如
`192.168.1.20`。然后通过 `http://NAS局域网IP:18080` 访问。如果端口已被占用，
把 `PORTFOLIO_WEB_PORT` 改成其他未占用端口即可；容器内部的 8080 不需要修改。
默认绑定 `127.0.0.1`，此时其他设备无法直接访问。

### 日常更新

在 `webapp` 目录执行：

```bash
./update-nas.sh
```

它会先为 SQLite 数据库创建一致性备份，再拉取 GitHub 最新代码、重新构建容器
并显示运行状态。备份位于 `data/backups/`。也可以手工执行：

```bash
git pull --ff-only
docker compose up -d --build
```

更新前建议在网页点击“导出备份”。建议只通过局域网或 VPN/Tailscale
访问，不要把网页端口直接暴露到公网。

## 使用方式

1. 第一次打开网页时设置登录账号和至少 8 位密码；密码以加盐哈希保存。
2. 在“总览”点击“添加持仓”保存初始买入；账户名称填写一次后会出现在下拉列表中。
3. 点击总览中的持仓名称，录入并保存实际加仓或减仓。
4. 在“交易流水”查看实际交易；基金卖出可展开查看消耗的买入批次。
5. 在“加减仓模拟”选择现有持仓做参考测算，模拟结果不会写入交易流水。
6. 使用“导出备份”定期保存 JSON 备份。

总览同时显示全部账户汇总和每个账户的独立持仓。同一代码在不同账户中分别计算。添加持仓和实际加减仓均支持金额、数量、净值填写任意两项后自动计算第三项，手续费单独显示。

费率设置页分别保存股票佣金和 ETF 佣金，不设默认基金费率。添加基金时可以选择 0%、0.15% 或自定义申购费率，并从已有基金规则或赎回规则模板中下拉复用。基金规则按“账户＋基金代码”保存并可修改。实际赎回按照买入批次 FIFO 计算，并永久保存本次卖出的来源批次、持有天数、费率与费用。

代码框旁的“查询”会通过公开行情接口自动填写名称、类型和最新价/净值。网络接口不可用时仍可手工填写，当前价格也会保存在本地 SQLite 中。

股票和 ETF 使用加权平均成本法；买入费用计入账面成本，卖出费用和税费减少卖出净收入。场外基金按买入批次保留成本，卖出时按最早批次结转成本并用于计算持有天数和赎回费。
